# VСмске

Социальная сеть в духе ВКонтакте: вход по почте и через Google, профиль, стена, лента друзей,
лайки, комментарии, заявки в друзья, поиск людей, личные сообщения с фото, статус «в сети»,
ВС Видео, ВС Альбомы, ВС Диск.

Сайт: https://nlponae269.github.io/vsmske/

Всё работает на бесплатном тарифе Firebase Spark: фото и файлы хранятся прямо в Firestore
(Firebase Storage не нужен).

## Из чего состоит

```
index.html        страница
style.css         оформление (светлая и тёмная тема)
app.js            вся логика и подключение Firebase
firestore.rules   правила доступа к базе (копия того, что вставлено в консоль Firebase)
tests/            проверка правил в эмуляторе (для разработчика, сайту не нужна)
```

## Как обновить сайт

1. На GitHub откройте репозиторий → **Add file → Upload files**.
2. Перетащите изменённые файлы (`index.html`, `app.js`, `style.css`) и нажмите **Commit changes**.
3. Через 1–2 минуты GitHub Pages покажет новую версию. Номер версии виден внизу страницы «Настройки».

## Как обновить правила доступа

1. Откройте https://console.firebase.google.com → проект **vsmske** → **Firestore Database** → вкладка **Rules**.
2. Удалите весь текст и вставьте содержимое файла `firestore.rules`.
3. Нажмите **Publish**.

## Что включено в консоли Firebase

- Authentication → Sign-in method: «Email/Password» и «Google».
- Authentication → Settings → Authorized domains: `nlponae269.github.io`.
- Firestore → Indexes: три составных индекса (см. `CLAUDE.md`).

## Данные в Firestore

| Коллекция | Что хранит |
|---|---|
| `users/{uid}` | имя, короткое имя, город, статус, о себе, аватар, друзья, приватность, когда был в сети |
| `usernames/{nick}` | кому принадлежит короткое имя |
| `friendRequests/{от_кому}` | заявки в друзья |
| `posts/{id}` + `comments` | записи на стене и комментарии |
| `chats/{uid1_uid2}` + `messages` | диалоги и сообщения (текст и фото) |
| `videos`, `files` + `chunks` | видео и файлы Диска (файлы кусками) |
| `albums`, `photos`, `photoFull` | альбомы, миниатюры и полные фото |

## Ограничения бесплатного тарифа

50 000 чтений и 20 000 записей в день, 1 ГБ данных.
