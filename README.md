# VСмске

Социальная сеть на Firebase: вход по почте и через Google, профиль, стена, лента друзей,
лайки, комментарии, заявки в друзья, поиск людей и личные сообщения в реальном времени.
Фото сжимаются в браузере и хранятся прямо в Firestore, поэтому подходит бесплатный тариф Spark.

## Что включить в консоли Firebase (один раз)

1. **Authentication → Sign-in method**: включите «Email/Password» и «Google».
2. **Firestore Database**: создайте базу (режим production, регион eur3).

## Как выложить сайт

Нужен Node.js (https://nodejs.org, версия LTS). В терминале:

```
npm install -g firebase-tools
firebase login
cd путь/к/папке/vsmske
firebase deploy
```

`firebase deploy` загружает сайт, правила доступа (`firestore.rules`) и индексы
(`firestore.indexes.json`). Сайт откроется по адресу https://vsmske.web.app.
Индексы создаются несколько минут. Если сразу после деплоя лента или сообщения
показывают ошибку про индекс, подождите 5 минут и обновите страницу.

После правок кода снова выполните `firebase deploy`.
Чтобы обновить только сайт: `firebase deploy --only hosting`.

## Проверка у себя на компьютере

```
cd vsmske
npx serve public
```

Откройте адрес, который покажет команда (обычно http://localhost:3000).
Двойной щелчок по index.html не подойдёт: вход Google и модули не работают с file://.

## Структура

```
public/index.html        страница
public/style.css         оформление (светлая и тёмная тема)
public/app.js            вся логика и подключение Firebase
firestore.rules          правила доступа
firestore.indexes.json   составные индексы для ленты, стены и чатов
firebase.json, .firebaserc   настройки проекта vsmske
```

## Данные в Firestore

| Коллекция | Что хранит |
|---|---|
| `users/{uid}` | имя, короткое имя, город, статус, о себе, аватар, список друзей, поисковые слова |
| `usernames/{nick}` | кому принадлежит короткое имя (следит за уникальностью) |
| `friendRequests/{от_кому}` | заявки в друзья |
| `posts/{id}` | записи: автор, чья стена, текст, фото, лайки, число комментариев |
| `posts/{id}/comments/{id}` | комментарии |
| `chats/{uid1_uid2}` | диалог: участники, последнее сообщение, когда кто прочитал |
| `chats/{uid1_uid2}/messages/{id}` | сообщения |

## Ограничения бесплатного тарифа

50 000 чтений и 20 000 записей в день. Для начала этого хватит с запасом.
Одна запись с фото занимает до ~0,7 МБ, всего в базе бесплатно 1 ГБ.
